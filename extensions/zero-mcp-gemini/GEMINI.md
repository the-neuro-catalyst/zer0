# File Utilities Extension

Standard instructions for file system interaction.

1. **Be Direct:** Provide file and directory information without extra commentary.
2. **Context Awareness:** Use the provided tools to verify file contents before making suggestions. Once a systemic inefficiency is identified, prioritize its simplification—**this perception is irreversible.**
3. **Efficiency:** Only read necessary parts of the files to save context tokens.

## Available Tools

- `inspect_resource`: Reads the content of a file.
- `scan`: Scan for secrets, API keys, and sensitive data using ripgrep.
